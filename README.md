# 🍽️ SmartCanteen AI
### AI-Powered Smart Canteen Management, Inventory & Sales Intelligence System

SmartCanteen AI is a web-based canteen management system designed to simplify food ordering, menu management, inventory tracking, and sales monitoring. It combines canteen operations with AI-assisted analytics to support smarter decisions and more efficient management.

## 📌 Project Overview

Traditional canteen management often involves manual order handling, inventory updates, and sales calculations. SmartCanteen AI aims to centralize these activities in one platform, making canteen operations easier to manage and monitor.

The system provides role-based access for administrators, managers, staff, and students, with features tailored to their responsibilities.

## ✨ Key Features

- **User Authentication:** Login, registration, and role-based access control.
- **Menu Management:** Manage food items, categories, prices, and menu availability.
- **Order Management:** Place orders and monitor their status.
- **Persistent Shopping Cart:** Maintain cart data for authenticated users.
- **Inventory Management:** Track stock and ingredient availability.
- **Supplier Management:** Maintain supplier information.
- **Recipe Management:** Organize recipe and ingredient information.
- **Sales Analytics:** Review sales data and business performance.
- **AI-Powered Insights:** Support demand forecasting, recommendations, and data-driven decisions.
- **AI Command Center:** Provide a centralized interface for supported AI-related tools.
- **Reports and Dashboard:** Present operational information through dashboards and visualizations.

*Note: The availability of individual features depends on the configured database and application setup.*

## 👥 User Roles

| Role | Purpose |
|---|---|
| Admin | Manage users, menu data, settings, and system operations |
| Manager | Monitor canteen operations, inventory, and reports |
| Staff | Handle assigned order-processing activities |
| Student | Browse the menu, manage the cart, and place orders |

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **Charts and Visualization:** Chart.js
- **Local Development Environment:** XAMPP
- **AI and Analytics:** AI-assisted forecasting, recommendations, and sales intelligence features

## 🗂️ Main Project Modules

- `admin/` — Administrative dashboards and management features
- `manager/` — Manager-facing operations
- `staff/` — Staff-facing order operations
- `student/` — Student ordering interface
- `auth/` — Authentication-related pages
- `api/` — Application API endpoints
- `ai/` — AI-related functionality
- `assets/` — Stylesheets, scripts, and images
- `config/` — Application configuration
- `database/` — Database-related documentation and resources
- `includes/` — Shared application components
- `tools/` — Utility and development tools
